Project Euler

LeetCode Project Euler

All 1,007 problems, the statement beside the editor, and Python running in the browser through Pyodide — CPython compiled to WebAssembly, downloaded the first time you press run. The seventy solutions already written sit here as saved Python, along with the data files they read; the rest are waiting.

Progress is kept per language, so switching to C++ empties the board and you start again in C++. Answers are deliberately not stored: run it, read the number, check it on projecteuler.net, then mark it solved.
