LeetCode

LeetCode Project Euler

All 4,033 problems, the statement beside the editor, and the examples run against your code without leaving the page. Python and JavaScript really execute — Python through Pyodide, which is CPython compiled to WebAssembly and downloaded the first time you press run. The other seven languages get the editor, the colouring, the checker and the formatter, but a browser cannot compile C++, so they stop short of running.

Progress is kept per language on purpose. Solving something in Python says nothing about solving it in C++, so switching the language switches which problems count as done. It is all in this browser's storage; the gist sync at the bottom is there if you use two machines.
